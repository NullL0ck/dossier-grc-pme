# Dossier GRC : Cabinet Delorme Conseil (cas d'étude fictif)

Dossier de gouvernance, risques et conformité réalisé dans le cadre de ma formation
en cybersécurité (Bachelor Expert en Cybersécurité, OTERIA Cyberschool).
Il suit une PME fictive, un cabinet d'expertise comptable, de son cadrage
jusqu'à son audit de conformité.

**Important : l'entreprise et ses données sont entièrement fictives.**
